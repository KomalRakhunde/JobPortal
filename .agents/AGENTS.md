# ApplyAI Project Rules & Standards

## Mandatory Guidelines

### 1. Device Responsiveness (CRITICAL)
- **EVERY PAGE AND COMPONENT MUST BE 100% RESPONSIVE** across all device viewports:
  - Mobile Phones (Android, iPhone SE/Pro/Max)
  - Tablets & Foldables (iPad Mini/Pro, Surface)
  - Laptops & MacBooks
  - Ultra-wide & Desktop Displays (Windows / Mac)
- Use mobile-first Tailwind CSS breakpoint utilities (`grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4`).
- Ensure touch targets are at least 44px on mobile and buttons scale with `w-full sm:w-auto`.
- Use fluid paddings (`px-3 sm:px-6 lg:px-8`) and scalable text (`text-xs sm:text-sm md:text-base`).

### 2. User Experience & Aesthetics
- Maintain clean, high-converting glassmorphic designs with the original color system (`bg-slate-50`, `bg-white`, `text-slate-900`, `indigo-600` accents).
- Keep student and recruiter workflows separate and role-tailored.
